# 🌐 Portfolio Web Personal

Este proyecto es mi portfolio web personal, desarrollado con el objetivo de mostrar mis habilidades, experiencia y áreas de especialización dentro del desarrollo de software.

## 🚀 Tecnologías utilizadas

- **Frontend:** React
- **Estilos:** CSS / librerías de componentes
- **Carruseles:** React Slick
- **Backend:** Node.js (para gestión de formularios de contacto)
- **Despliegue:** Vercel (frontend) + servicio backend

## ✨ Funcionalidades principales

### 🧑‍💻 Sección de presentación personal  
Breve introducción sobre mí, perfil profesional, habilidades y proyectos.

### 🛠 Áreas de especialización  
Implementadas mediante un carrusel de tarjetas que incluyen:
- Desarrollo Backend (Java)
- Bases de datos
- APIs REST y microservicios
- Testing y calidad de software
- CI/CD y entornos de desarrollo
- Metodologías ágiles
- Inteligencia Artificial / LLMs

### 📊 Nivel de habilidades  
Cada tarjeta muestra el nivel (básico, intermedio, avanzado) mediante barras visuales alineadas para una mejor experiencia de usuario.

### 📬 Formulario de contacto  
Permite a los usuarios enviarme mensajes directamente:
- Integración con backend en Node.js
- Envío de emails automático
- Validación de datos

### 🎨 Diseño responsive  
Adaptado a diferentes tamaños de pantalla (móvil, tablet y escritorio).

## 🧪 Entorno de desarrollo local

Para facilitar las pruebas en local del formulario de contacto, se ha implementado un pequeño servidor en Node.js (`server.js`).

Este servidor:
- Gestiona el envío de emails desde el formulario
- Permite testear la funcionalidad sin necesidad de desplegar el backend
- Está pensado únicamente como entorno de desarrollo/pruebas

> ⚠️ En producción, este servicio debe desplegarse en una plataforma externa.
